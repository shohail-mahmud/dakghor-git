# Dakghor Git

DAKGHOR — UI REFINEMENT PASS ONLY

IMPORTANT:

DO NOT START THE DESIGN OVER.

The current Dakghor design direction is already working and should be PRESERVED.

This is a refinement pass, not a redesign.

Keep the existing:

- Overall visual identity

- Typography direction

- Color palette

- Logo

- Postal aesthetic

- General composition

- Existing components

- Existing page structure where it already works

Make ONLY the following improvements.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. REMOVE THE DECORATIVE DOTS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Remove the small decorative red dots appearing around the interface, especially the tiny red dot beside the Dakghor wordmark.

The Dakghor wordmark should simply read:

Dakghor

No decorative red dot beside it.

Remove unnecessary decorative dots throughout the UI if they are being used purely as decoration.

Do NOT replace them with another decorative element.

Keep the design clean.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. ADD MORE DEPTH TO UI ELEMENTS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The current design is clean, but some elements feel too flat.

Add subtle physical depth to important elements.

Use restrained techniques such as:

- Layering

- Subtle shadows

- Slight elevation

- Paper-like surfaces

- Thin borders

- Overlapping postal elements

- Small changes in surface tone

- Subtle dimensional separation

The depth should feel tactile and editorial.

Think physical paper, envelopes, stamps and printed objects.

DO NOT use:

- Heavy shadows

- Neon glow

- Glassmorphism

- 3D effects

- Floating glass cards

- Excessive gradients

The goal is subtle depth, not a 3D interface.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3. REMOVE SHARP CORNERS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

There should be NO harsh square/sharp corners on interactive UI components.

Apply a consistent rounded-corner language to:

- Buttons

- Inputs

- Form controls

- Cards

- Navigation containers

- Interactive elements

- Modal/dialog surfaces where applicable

Keep the radius tasteful and consistent.

Do NOT make everything an exaggerated pill.

The interface should feel softly rounded, modern and tactile.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4. SIMPLIFY THE HERO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The hero currently contains too much visual information.

Simplify it.

The hero should communicate the idea of Dakghor immediately.

Prioritize:

- Strong typography

- The Dakghor identity

- One clear central message

- One primary action

- One subtle postal visual element

Remove unnecessary hero decorations, secondary information and competing visual elements.

Do NOT add more cards or more content to compensate.

Give the main idea room to breathe.

The hero should feel confident and editorial rather than like a startup landing-page template.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5. PROPER WEBSITE NAVIGATION

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Make the website navigation complete and functional.

This is a MULTI-PAGE WEBSITE.

Do NOT make it feel like a single scrolling landing page.

Create clear navigation between the actual pages.

PUBLIC NAVIGATION:

DAKGHOR

HOW IT WORKS

ABOUT

SIGN IN

CREATE ACCOUNT

Application navigation should include:

POSTBOX

WRITE LETTER

MY ADDRESS

MY LETTERS

SETTINGS

Every navigation item should lead to the appropriate page.

Clearly indicate the current/active page.

Navigation should feel consistent across the website.

Do not create unnecessary navigation items.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6. DEDICATED MOBILE LAYOUT

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Do NOT simply scale down the desktop design for mobile.

Create a dedicated responsive mobile layout.

Mobile should have its own thoughtful composition.

Pay particular attention to:

- Navigation

- Hero typography

- Letter layouts

- Forms

- Buttons

- Spacing

- Postbox

- Address presentation

- Footer

Use a proper mobile navigation pattern.

Do not allow desktop navigation to become cramped or overflow horizontally.

The mobile version should feel intentionally designed, not like a desktop website squeezed into a phone.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7. CLEAN LOGIN PAGE

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Simplify the login page significantly.

The login experience should feel calm, focused and polished.

Prioritize:

DAKGHOR

SIGN IN

Email / required credential fields

Password

SIGN IN

Create Account

Remove unnecessary decorative elements and excessive information.

Do not turn the login page into a marketing page.

Give the form enough breathing room.

Use the Dakghor typography and color system consistently.

8. SIMPLIFY THE FOOTER

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Keep only useful information:

About

- Duplicate navigation

- Unnecessary categories

- Fake social links

- Repeated information

- Excessive legal-style sections

- Large empty footer areas

The footer should feel like a quiet ending to the page.
